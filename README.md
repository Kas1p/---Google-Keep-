# ---Google-Keep-

# Отчёт по тестированию ПО — Веб-приложение “Google Keep”

## 1. Введение

### Цель работы:
Провести системное тестирование веб-приложения “Google Keep” для проверки корректности работы функционала, выявления дефектов и оценки соответствия требованиям.

### Краткое описание программы:
Веб-приложение позволяет создавать заметки, списки задач, добавлять изображения, устанавливать напоминания и синхронизировать данные между устройствами.

### Обоснование тестирования:
Системное тестирование необходимо для оценки поведения приложения с точки зрения конечного пользователя, проверки соответствия требованиям (SRS), интерфейса и производительности.

---

## 2. Тест-план (Test Plan)

### 2.1 Цели и задачи
- Проверка создания, редактирования и удаления заметок  
- Проверка работы чек-листов  
- Проверка напоминаний  
- Проверка синхронизации  
- Проверка поиска заметок  
- Выявление ошибок и дефектов  

### 2.2 Область применения

**Тестируемые модули:**
- Модуль заметок  
- Модуль чек-листов  
- Модуль напоминаний  
- Модуль поиска  
- Модуль архива  
- Модуль синхронизации  

**Ограничения:**
- Тестирование проводится в браузере на desktop  

### 2.3 Стратегия тестирования
- Функциональное тестирование всех модулей  
- Регрессионное тестирование после исправления багов  
- GUI тестирование интерфейса  
- Smoke-тестирование основных функций (создание заметки, удаление, поиск)  

### 2.4 Критерии начала тестирования
- Приложение доступно  
- Пользователь может создать заметку  
- Интерфейс корректно отображается  

### 2.5 Критерии завершения тестирования
- Выполнено ≥ 90% тест-кейсов  
- Все критические баги зарегистрированы  
- Основной функционал работает корректно  
- Пользовательские сценарии выполняются без ошибок  

### 2.6 Тестовая среда
- ОС: GNU/Linux / MacOS / Windows  
- Браузер: Chrome / Firefox  
- Интернет-соединение
